# lab_1

## Помощник по личным расходам

**Назначение агента:** помощь пользователю в контролировании личных расходов.

**Выбранный язык программирования:** `Python`

## Функционал

- Добавлять расходы
- Распределять расходы по категориям
- Показывать суммы за период

## Запросы пользователя и ожидаемые результаты

**Запрос:** -500 на обязательные продукты
**Ожидаемый результат:** расход добавлен в учёт.

**Запрос:** +1000 доход
**Ожидаемый результат:** доход добавлен в учёт.

**Запрос:** Просмотр покупок
**Ожидаемый результат:** [список предыдущих покупок].
