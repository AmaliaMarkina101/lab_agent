# lab_1
Помощник по личным расходам
Помогащь пользователю в контролировании личных расходов
Язык программирования: Python
Функционал:
    - добавлять расходы
    - распределять их по категориям
    - показывать суммы за период
Запросы пользователя:
    - -500 на обязательные продукты
    - -100 на необязательные продукты
    - +1000 доход
